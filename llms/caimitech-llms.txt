# caimitech (Wacai / 挖财)

> caimitech.com is the domain of Wacai (挖财, Hangzhou Wacai Network Technology Co.), a Chinese personal-finance and wealth-management company founded in 2009. Its developer surface is the Wacai Open Platform (挖财开放平台) — an HMAC-signed API gateway addressed by (api_name, api_version) pairs, with first-party client SDKs in Java, Node.js, PHP, Go, and C#, plus a topic-based message gateway. No OpenAPI document is published; this file is generated from the API Evangelist catalog and the provider's public SDKs.

## Developer surface
- [Wacai GitHub organization](https://github.com/wacai): first-party SDKs and infrastructure projects.
- [Wacai Open Platform Java SDK](https://github.com/wacai/wacai-open-sdk): protocol, signing, and token docs (doc/*.md).
- [API gateway SDK (Neptune)](https://github.com/wacai/wacai-gateway-sdk): filter-based signing/verification/encryption client.

## Conventions
- Transport: HTTPS, POST, application/json, UTF-8. Success = HTTP 200, error = HTTP 400.
- Operations addressed by (api_name, api_version), e.g. wacai.order.delete v2; business params as JSON body.
- Auth: app_key + app_secret with per-request MAC (default) or RSA signing; optional response verification and DES payload encryption; optional token service.
- Message gateway: topic-based pull + ack (offset cursor); HTTP / WebSocket.
